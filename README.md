#### 📈 MLBII — Bidirectional Iterative Imputation for Time Series
> **Status:** First-author manuscript under review at *Engineering Applications of Artificial Intelligence*.
>
> **Key Features:** Built a PyTorch + scikit-learn framework for imputing long continuous gaps in multivariate time series. Achieved NSE `0.9359`, outperforming SAITS and BRITS, while reducing compute time by up to `97x` vs BRITS. Validated on 43 meteorological stations across Vietnam.
>
> **Tech Stack:** `PyTorch` • `scikit-learn` • `Pandas` • `NumPy` • `Seaborn`

#### 🔎 Tiny Object Detection via Anisotropic Log-Wasserstein (ALW)
> **Status:** January 2026 – present.
>
> **Key Features:** Proposed ALW, a Gaussian-based loss with anisotropic, scale-invariant modeling for tiny-object localization on COCO. Integrated the loss into Faster R-CNN with ResNet-50, reaching AP@50:75 of `0.1899` and outperforming prior Gaussian-based losses.
>
> **Tech Stack:** `PyTorch` • `Faster R-CNN` • `ResNet-50` • `COCO`

#### 🌊 Flood Forecasting with Multi-Source Satellite Data
> **Status:** January 2026 – March 2026.
>
> **Key Features:** Designed an automated ETL pipeline for daily flood forecasting with multi-source satellite data, connecting geospatial data extraction, workflow orchestration, containerized processing, and database storage.
>
